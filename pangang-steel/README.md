# 弄弄坪 · 提钒炼钢 —— 攀钢转炉炼钢流程 3D 演示

一个可交互的 Three.js 网页，按攀钢（攀枝花弄弄坪厂区）的"提钒 + 炼钢"双联工艺，演示一炉钢从铁水到钢坯的完整流程：

1. 铁水进站
2. 铁水脱硫与扒渣
3. 提钒转炉：吹炼、出半钢、倒钒渣
4. 炼钢转炉：兑半钢、吹炼、测温取样、出钢、溅渣护炉、倒渣
5. LF 精炼
6. RH 真空处理
7. 板坯连铸与火焰切割

左下角的转炉剖面小窗和动画同步，可以看到钢水、渣层、出钢口和氧枪的位置关系。

## 使用

直接打开 `index.html`，或访问本仓库的 GitHub Pages。拖动旋转视角，滚轮缩放，用底部按钮切换工序、暂停或调速。

## 说明

- 设备尺寸按 120 吨级转炉、钢包、RH 和板坯连铸机的通用设计比例建模（1 单位 = 1 米）。各设备间距做了压缩，便于在一个画面里看完全流程。
- 面板中的温度和成分读数是典型示意值，实际随炉次和钢种变化。
- 三维引擎通过 CDN 加载 three.js r128，需要联网。
